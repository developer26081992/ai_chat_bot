AI CHATBOT - PORTABLE SOURCE COPY

Repository: https://github.com/developer26081992/ai_chat_bot
Live URL: see the Deployment links section in README.md.

1. Install Node.js 22 LTS (with npm). Internet access is required.
2. Copy the source folder from the flash drive to a local folder.
3. Copy .env.example to .env and enter your own Neon, Clerk and OpenAI values.
4. Open a terminal in the source folder and run:
     npm ci
     npm run check:env
     npm run db:migrate
     npm run dev
5. Open http://localhost:3000, sign in, and upload both PDFs in samples/.
6. Open /chat, choose the documents, and ask the questions in samples/README.md.

On Windows you can alternatively run:
  powershell -ExecutionPolicy Bypass -File scripts/start-local.ps1

For a production-style local build after configuration:
  npm run build
  npm start

The copy contains the complete source code, lockfile, database migrations,
tests and two readable sample PDFs. Dependencies are installed by npm ci.
Clerk, OpenAI and the Neon database are online services; this is not an offline
replacement for those services. Actual credentials are not included.

If this folder contains SHA256SUMS.json, verify the copy before editing it:
  node scripts/verify-portable.mjs
